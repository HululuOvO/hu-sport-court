# HU Sport Court｜赛后小法庭

作者：胡睿哲 Roy Hu

- 项目介绍：https://hululuovo.github.io/hu-sport-court/#/
- 进入体验：https://hululuovo.github.io/hu-sport-court/#/courts

## 我想做什么

把足球赛后的争议，变成一个更容易参与、观点更清楚的讨论场景。一场比赛结束后，有人想批评，有人想解释，也有人只想安静地看看。小法庭用「一场比赛、一个议题」把这些看法组织起来，让球迷可以发言，也可以只投一票。

## 已经可以体验的功能

| 功能 | 用户可以做什么 |
| --- | --- |
| 法庭大厅 | 按开庭中、已结案、预约中等状态筛选示例场次 |
| 开庭动画 | 从比赛入口进入，短暂的天秤摇摆与幕布打开后进入法庭；支持跳过和减少动态效果 |
| 正反方观点 | 先看双方主张、代表发言和支持率，再决定如何参与 |
| 辩论席 | 按正方、反方或不站队发表意见；查看热评、点赞、回复和展开讨论 |
| 陪审席 | 不发言也能投票；确认选择后更新示例计数，也能修改观点 |
| 庭审记录 | 已结案示例可以查看投票分布与结果 |
| 其他场次 | 在法庭内切换到另一场比赛，继续参与对应议题 |
| 体验昵称 | 自定义当前体验中的发言昵称，无需注册 |
| 手机适配 | 在手机竖屏和桌面端使用同一套核心流程 |

介绍页也提供一个轻量的观点选择预览，帮助第一次看到作品的人理解玩法。完整发言与投票在「立即体验」后的法庭中进行。

## 我在项目中的工作

从球迷视角提出产品想法，确定讨论流程、信息层级与互动方式，借助 AI 辅助完成前端设计和代码实现，并根据使用反馈持续修改视觉与交互。目标是做出可以点击体验的作品，让面试官能够实际了解产品思路。

## 当前版本和后续方向

当前版本是可交互的前端作品演示，比赛、发言和基础投票均为示例。新增发言、点赞、回复和投票只保留于当前页面会话，刷新后重置，不会同步给其他访客。开庭中的示例保持可体验，倒计时不代表真实比赛的审判期限。

AI 观点摘要尚未接入。下一步希望让 AI 整理正反方的主要论点，帮助后来加入的用户快速了解讨论；再逐步考虑比赛数据接入、多人同步和长期保存。当前没有宣称已提供实时赛事数据或 AI 自动判决。

## 介绍页的设计

参考用户提供的 Steep 风格文件：白色画布、衬线中文标题、大留白、胶囊按钮、少量桃色点缀和产品界面片段。结合原 HU 标识、真实球队队徽、比分和球场线条。保留原有小法庭的红蓝对抗界面。

首页 `#/` 展示项目介绍；体验入口为 `#/courts`；原有 `#/court/场次` 深链接继续可用。社区、资讯与榜单仍保留源码，不在本作品展示版中开放。


### 足球场景与动效更新

根据反馈，介绍页首屏改为文字与球场场景并列：真实球场照片、醒目的队徽与比分、红蓝观点及示例比赛条带。加入分层入场、卡片悬浮、鼠标轻倾斜、滚动出现和投票计数反馈；减少动态效果偏好下取消动画。原有法庭页面与交互继续保留。


### 三段式介绍与宋体更新

介绍页精简为认识法庭、玩法演示、进入体验三部分。玩法使用固定界面随滚动切换辩论、投票与不站队，支持手动切换；上一屏与下一屏按钮提供平滑定位。介绍与正式法庭之间使用浏览器原生页面转场，减少动态效果时直接切换。删除重复说明，使用较大、较粗的宋体呈现标题、观点和必要文案。原有法庭视觉与交互保留。


### 字体与连续面板转场

最新反馈要求字体更清晰，并让第一页的比赛面板自然连接到第二页。介绍页改用苹方为主的黑体组合，保留清楚的字号和字重层级。首屏与玩法区共用同一个面板元素，滚动时按两个实际位置连续插值移动、缩放并展开；向上滚动可沿原路返回。到达玩法区后继续切换辩论、投票和中立观点。窗口尺寸或字体加载变化时重新测量；减少动态效果时取消飞行动画。

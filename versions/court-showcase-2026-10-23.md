## 如何恢复完整版

1. 将 app/src/showcase-config.js 内的 COURT_ONLY 改为 false。
2. 在 app/ 运行 npm run build。
3. 通过原有 GitHub Pages 工作流发布到同一个网址。

这是可恢复的展示模式。无需重新编写社区、资讯或榜单。
